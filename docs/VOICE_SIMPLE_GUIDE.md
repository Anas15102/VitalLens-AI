# Voice Features - Simple Guide 🎤

## 🎯 **The Simple Truth**

**Voice input only works reliably in Chrome or Edge.**

Other browsers (Brave, Safari, Firefox) have limited or no support.

---

## ✅ **Two Options:**

### **Option 1: Use Chrome (Full Voice Features)**
1. Download Chrome: https://www.google.com/chrome/
2. Open: https://localhost:5001/ai-chat.html
3. Click "Speak" → Allow microphone → Talk!
4. ✅ Voice input works perfectly

### **Option 2: Use Text Input (Any Browser)**
1. Stay in your current browser (Brave/Safari/etc)
2. Type your symptoms in the text box
3. Click "Read Aloud" to hear AI responses
4. ✅ Same great AI, no voice input needed

---

## 🌐 **Browser Support:**

| Browser | Voice Input | Recommendation |
|---------|-------------|----------------|
| Chrome  | ✅ Works    | **Use this!** |
| Edge    | ✅ Works    | **Use this!** |
| Brave   | ❌ Blocked  | Use text input |
| Safari  | ❌ Limited  | Use text input |
| Firefox | ❌ None     | Use text input |

---

## 💡 **Why This Happens:**

- **Chrome/Edge:** Built by Google/Microsoft, have direct access to speech APIs
- **Brave:** Blocks Google services for privacy (including speech API)
- **Safari:** Poor Web Speech API implementation
- **Firefox:** Doesn't support Web Speech API
