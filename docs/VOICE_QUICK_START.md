# Voice Features - Quick Start Guide 🎤

## ✅ **HTTPS Server is Running!**

Voice features are now enabled with HTTPS support.

---

## 🚀 **3 Simple Steps:**

### **Step 1: Open the Link**
```
https://localhost:5001/ai-chat.html
```

### **Step 2: Accept Security Warning**
- Click **"Advanced"** → **"Proceed to localhost"**
- This is safe for local development!

### **Step 3: Use Voice!**
- Click **"Speak"** → Allow microphone → Start speaking!
- Click **"Read Aloud"** → Hear AI responses!

---

## 🎤 **Voice Commands:**

### **English:**
- "I have a headache for three days"
- "My blood pressure is high"
- "I feel dizzy and nauseous"

### **Hindi (हिंदी):**
- "मुझे सिर दर्द है" (I have a headache)
- "मेरा पेट दुख रहा है" (My stomach hurts)
- "मुझे बुखार है" (I have fever)

---

## 🔧 **Server Commands:**

### **Start Server:**
```bash
python start_vitallens_https.py
```

### **Stop Server:**
Press `Ctrl+C`

### **Regenerate Certificate:**
```bash
python generate_ssl_cert.py
```
